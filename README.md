# Pró-Estágio

Protótipo navegável do app **Pró-Estágio**, que reúne vagas de estágio, currículo e
contato com empresas num só lugar. Feito em React + TypeScript (Vite).

**Acesse:** https://fellipedsg.github.io/pro-estagio/

## Rodar no computador

Precisa do [Node.js](https://nodejs.org) 18 ou mais novo.

```bash
git clone https://github.com/Fellipedsg/pro-estagio.git
cd pro-estagio
npm install
npm run dev
```

Abre em http://localhost:5173.

## Publicar alterações

Cada `git push` na branch `main` atualiza o site automaticamente (GitHub Actions →
GitHub Pages). O link continua o mesmo.

Os dados do app são fictícios.
